B-1進捗管理

業務進捗管理システム

橋ごと・工程ごとの進み具合を、複数人がブラウザで同時に更新できる進捗表です。

以前
紙で進捗を管理していて、更新されないまま古い情報が残っていることが多かった。
今
更新したその場で、約15秒後には全員の画面に反映。誰がいつ更新したかも残る。
  • 状態を色で表示（作業中＝黄、優先＝赤、一時停止＝橙、完了＝緑）
  • 誰がいつ更新したかを自動で記録し、履歴を後から確認できる
  • 行・列の見出しを入れたExcelを読み込むだけで表ができる
  • 利用者登録は承認制、プロジェクトごとに参加者を制限
社内LAN版社内PC 1台をサーバーにして動かす。インターネットに出さずに使える。
Google版Googleドライブ上で動く。サーバーPC不要で、スマホからも使える。
Python / FlaskSQLiteGoogle Apps ScriptスプレッドシートHTML / JavaScript
B-2地図資料

位置マップ一覧

番号・名前・緯度経度の一覧表を読み込むと、旗と番号を立てた地図と一覧表が並んだ資料ができます。

以前
橋の位置を手作業で調べて地図に印を付けていたため、件数によっては丸1日かかっていた。
今
一覧表を選ぶだけで、旗付きの地図と一覧表がその場で完成。
  • Excel・CSVの見出しを自動で探して列を判定（2段・3段の見出しにも対応）
  • 「当初」と「変更」の座標が並ぶ表では、変更側を自動で選ぶ
  • 全地点が収まる縮尺に自動調整、一覧の行をクリックするとその地点へ移動
  • A3（地図と一覧を1枚）とA4（2枚に分割）で印刷・PDF保存
  • 背景は国土地理院の標準地図・航空写真・淡色地図から選択
HTML 1ファイルLeafletSheetJS地理院タイル
B-3写真整理

写真の橋梁別分類

1日分の点検写真を撮影順に並べ、損傷図の用紙に書かれた「橋梁名」を文字認識で読み取って、橋ごとのフォルダーにコピーします。

以前
1日に何橋も回ると写真が数百〜千枚になり、橋ごとに手で振り分けていた。
今
1,000枚を約1分で仕分け。ダブルクリックで実行するだけ。
  • 橋梁名の写真から、次の橋梁名の写真の手前までを同じ橋として扱う
  • 元の写真は動かさず、コピーだけを作る
  • 読み取りが怪しい写真には「確認してください」と印を付けて一覧に出す
  • 手書きの読み間違いは補正表に1行足せば、次回から自動で直る
  • Windows標準の日本語OCRを使うので、追加のソフトは不要
PowerShellWindows OCR（日本語）CSV
B-4経費精算

交通費請求資料作成

交通系ICカードの利用履歴（CSV）を読み込み、画面で確認・修正して、提出用のExcel一覧表を出力します。

以前
利用明細を見ながら請求資料を作成。PiTaPaは定期登録・区間指定の分が月額の定額になるため、明細を足しても実際の請求額と合わない。
今
CSVを読み込むだけで提出用Excelが完成。請求額と1円単位で照合済み。
  • PiTaPa・モバイルSuicaなどの形式と文字コードを自動で判別
  • 定額分と実費分を分けて、鉄道・バス会社ごとに集計
  • CSV末尾の支払額と照合し、合わないときだけ警告を表示
  • 土日祝をまとめて対象外にできる（祝日はネット接続なしで判定）。外した分は合計にすぐ反映
  • いつもの通勤と違う経路を薄い黄色で示し、確認漏れを防ぐ
  • 26項目の自動テストで、直すたびに計算結果が変わっていないか確認
PythonopenpyxlHTML / JavaScript自動テスト

P-1写真加工

画像加工Pro

撮った写真や手持ちの写真に、スタンプ・文字・吹き出しを貼ったり、漫画風に仕上げたりして遊べるスマホ向けアプリです。

  • セリフ・人物顔・食べ物・乗り物などのスタンプをタップで追加。指で移動、2本指で拡大・回転
  • 吹き出しと文字入れ（縦書き・横書き、フチ・影）。貼ったあとも書き直せる
  • セピア・モノクロなどの写真加工。「タップで人物を選ぶ」で人物だけを前に出し、背景だけを加工できる
  • 集中線・スピード線などの効果線、効果音、コマ枠で漫画風に。写真を並べて4コマ漫画も作れる
  • プライベートモード：写っている人の顔を自動で見つけて隠す
  • 「おまかせガチャ」でランダムに飾り付け、ジョークの「AI診断」も
  • スタンプ工房（P-2）で作ったスタンプが「マイ帳」に並び、そのまま写真に貼れる
  • 写真はスマホの外に送らない。顔の認識や人物の切り抜きもスマホの中で処理
HTML / CanvasMediaPipe（顔検出・人物切り抜き）スマホ対応
P-2スタンプ作成

スタンプ工房

写真・手描き・文字・ハンコなどから、オリジナルのスタンプを作るアプリです。作ったスタンプは画像加工Pro（P-1）でそのまま写真に貼れます。

  • 作り方は8種類。写真からイラスト、顔写真から似顔絵、手描き、文字、ハンコ、コラージュ、写真の切り抜きから選ぶ
  • 写真の中の欲しい物をタップするだけで、AIが範囲を選んで切り取る。ブラシで直すこともできる
  • アニメ調・ポップ・水彩・色えんぴつ・ドット絵などのスタイルでイラストに変換
  • ハンコは丸印・角印・日付印・矢印など8種類の形と10種類の書体。かすれ・にじみで紙に押したような風合いに
  • 文字スタンプは12種類のデザイン。テーマを選ぶと言葉の候補と配色がおまかせで決まる
  • PNG、動くGIF、LINEスタンプ申請用のZIP、Discord・Slackの絵文字、シール用紙への印刷で書き出せる
  • 写真は端末の外に送らない。切り取りや顔の検出も端末の中で処理
HTML / CanvasMediaPipe（タップで切り取り・顔検出）GIF / ZIP書き出しスマホ対応

自分

CLAUDE CODE

コードの作成。作り方や設計で迷ったときの相談相手

  1. STEP 1困りごとを言葉にする現場で何に時間がかかっているか、どう使いたいかを日本語でClaude Codeに伝える。
  2. STEP 2試作して現場で使うできたものを実際の業務データで試し、使いにくい点を洗い出す。
  3. STEP 3直して、説明書まで作る修正を重ね、ほかの人も使えるよう操作説明書や導入手順も整える。
