できること

コードはClaude Codeが書きます。自分が担当しているのは次の4つです。

  1. 1

    現場の困りごとを整理する

    何に時間がかかっているか、どう使いたいかを言葉にして、Claude Codeに日本語で伝えます。

    • B-1紙の進捗表が更新されず、古い情報が残る
    • B-31日で千枚近くになる写真を手で振り分けている
  2. 2

    何を作るかを決める

    使う人と場面に合わせて、道具の形と守ることを決めます。

    • B-1社内LAN版とGoogle版の2通りを用意
    • B-3元の写真は動かさず、コピーだけを作る
    • P-1写真はスマホの外に送らない
  3. 3

    実際のデータで確かめる

    できたものを業務データで試し、結果が合っているかを数字で確認します。

    • B-4請求額と1円単位で照合、26項目の自動テスト
    • B-3読み取りが怪しい写真に印を付けて一覧に出す
  4. 4

    ほかの人が使える形に仕上げる

    修正を重ね、操作説明書や導入手順まで整えます。

    • B-3ダブルクリックで実行、追加のソフトは不要
    • B-1利用者登録は承認制、参加者をプロジェクトごとに制限
    • P-2使い方説明書を作成し、改訂を重ねている

B-1進捗管理

業務進捗管理システム

橋ごと・工程ごとの進み具合を、複数人がブラウザで同時に更新できる進捗表です。

困りごと
紙で進捗を管理していて、更新されないまま古い情報が残っていることが多かった。
工夫
状態を色で示し、誰がいつ更新したかを自動で記録。職場の環境に合わせて選べるよう、社内LAN版とGoogle版を用意した。
成果
更新したその場で、約15秒後には全員の画面に反映。誰がいつ更新したかも残る。
  • 状態は4色（作業中＝黄、優先＝赤、一時停止＝橙、完了＝緑）。更新の履歴を後から確認できる
  • 行・列の見出しを入れたExcelを読み込むだけで表ができる
  • 利用者登録は承認制、プロジェクトごとに参加者を制限
社内LAN版社内PC 1台をサーバーにして動かす。インターネットに出さずに使える。
Google版Googleドライブ上で動く。サーバーPC不要で、スマホからも使える。
Python / FlaskSQLiteGoogle Apps ScriptスプレッドシートHTML / JavaScript
B-2地図資料

位置マップ一覧

番号・名前・緯度経度の一覧表を読み込むと、旗と番号を立てた地図と一覧表が並んだ資料ができます。

困りごと
橋の位置を手作業で調べて地図に印を付けていたため、件数によっては丸1日かかっていた。
工夫
Excel・CSVの見出しを自動で探して列を判定する。見出しが2段・3段の表でも、そのまま読み込める。
成果
一覧表を選ぶだけで、旗付きの地図と一覧表がその場で完成。
  • 「当初」と「変更」の座標が並ぶ表では、変更側を自動で選ぶ
  • 全地点が収まる縮尺に自動調整、一覧の行をクリックするとその地点へ移動
  • A3（地図と一覧を1枚）とA4（2枚に分割）で印刷・PDF保存
  • 背景は国土地理院の標準地図・航空写真・淡色地図から選択
HTML 1ファイルLeafletSheetJS地理院タイル
B-3写真整理

写真の橋梁別分類

1日分の点検写真を撮影順に並べ、損傷図の用紙に書かれた「橋梁名」を文字認識で読み取って、橋ごとのフォルダーにコピーします。

困りごと
1日に何橋も回ると写真が数百〜千枚になり、橋ごとに手で振り分けていた。
工夫
元の写真は動かさず、コピーだけを作る。読み取りが怪しい写真には「確認してください」と印を付けて一覧に出す。
成果
1,000枚を約1分で仕分け。ダブルクリックで実行するだけ。
  • 橋梁名の写真から、次の橋梁名の写真の手前までを同じ橋として扱う
  • 手書きの読み間違いは補正表に1行足せば、次回から自動で直る
  • Windows標準の日本語OCRを使うので、追加のソフトは不要
PowerShellWindows OCR（日本語）CSV
B-4経費精算

交通費請求資料作成

交通系ICカードの利用履歴（CSV）を読み込み、画面で確認・修正して、提出用のExcel一覧表を出力します。

困りごと
利用明細を見ながら請求資料を作成。PiTaPaは定期登録・区間指定の分が月額の定額になるため、明細を足しても実際の請求額と合わない。
工夫
定額分と実費分を分けて、鉄道・バス会社ごとに集計。CSV末尾の支払額と照合し、合わないときだけ警告を出す。
成果
CSVを読み込むだけで提出用Excelが完成。請求額と1円単位で照合済み。
  • PiTaPa・モバイルSuicaなどの形式と文字コードを自動で判別
  • 土日祝をまとめて対象外にできる（祝日はネット接続なしで判定）。外した分は合計にすぐ反映
  • いつもの通勤と違う経路を薄い黄色で示し、確認漏れを防ぐ
  • 26項目の自動テストで、直すたびに計算結果が変わっていないか確認
PythonopenpyxlHTML / JavaScript自動テスト

P-1写真加工

画像加工Pro

撮った写真や手持ちの写真に、スタンプ・文字・吹き出しを貼ったり、漫画風に仕上げたりして遊べるスマホ向けアプリです。

工夫
写真はスマホの外に送らない。顔の認識や人物の切り抜きもスマホの中で処理する。
  • セリフ・人物顔・食べ物・乗り物などのスタンプをタップで追加。指で移動、2本指で拡大・回転
  • 集中線・スピード線などの効果線、効果音、コマ枠で漫画風に。写真を並べて4コマ漫画も作れる
  • プライベートモード：写っている人の顔を自動で見つけて隠す
  • スタンプ工房（P-2）で作ったスタンプが「マイ帳」に並び、そのまま写真に貼れる
ほかの機能（4件）
  • 吹き出しと文字入れ（縦書き・横書き、フチ・影）。書体はスタンプ工房と共通のものから選べ、貼ったあとも書き直せる
  • スマホのホーム画面に追加でき、通信がないときでも開ける
  • セピア・モノクロなどの写真加工。「タップで人物を選ぶ」で人物だけを前に出し、背景だけを加工できる
  • 「おまかせガチャ」でランダムに飾り付け、ジョークの「AI診断」も
HTML / CanvasMediaPipe（顔検出・人物切り抜き）ホーム画面に追加（PWA）スマホ対応
P-2スタンプ作成

スタンプ工房

写真から切り抜く方法と、手描き・ロゴ・ハンコなど一から作る方法で、オリジナルのスタンプを作るアプリです。作ったスタンプは画像加工Pro（P-1）でそのまま写真に貼れます。

工夫
保存したスタンプは画像加工Proに自動で並ぶ。写真は端末の外に送らず、切り抜きや顔の検出も端末の中で処理する。
  • はじめの画面は3つのタブ。写真から作る「切り抜き系」4つ（イラスト2種・似顔絵・写真のまま）、一から作る「製作系」4つ（手描き製作・ロゴ製作・ハンコ製作・コラージュ）、「作ったスタンプ」の一覧を切り替える
  • 写真の中の欲しい物をタップするだけで、AIが範囲を選んで切り抜く。欠けた所はもう一度タップするか、ブラシで直せる
  • ハンコ製作は丸印・角印・日付印・矢印など8種類の形。書体は全部の作り方で共通の22種類と、ハンコ専用の3種類。かすれ・にじみで紙に押したような風合いに
  • PNG、動くGIF、LINEスタンプ申請用のZIP、Discord・Slackの絵文字、シール用紙への印刷で書き出せる
ほかの機能（4件）
  • アニメ調・水彩・油絵・スケッチ・版画・ドット絵などのスタイルでイラストに変換。見本を大きく並べて見比べられる
  • 作ったスタンプは、タップで開くメニューから名前の変更や書き出しができる。バックアップをファイルに保存して、機種変更のあとに読み込める
  • スマホのホーム画面に追加でき、通信がないときでも開ける
  • ロゴ製作は13種類のデザイン。テーマを選ぶと言葉の候補と配色がおまかせで決まる
HTML / CanvasMediaPipe（タップで切り抜き・顔検出）GIF / ZIP書き出しホーム画面に追加（PWA）スマホ対応
